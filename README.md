# 누군가의 다음

미륵사지 석탑에 이어진 마음들을 만나는 웹 전시입니다.

## GitHub Pages 게시

이 폴더 **안의 파일과 assets 폴더**를 저장소 최상위에 업로드합니다. index.html이 저장소 첫 화면에서 바로 보여야 합니다.

1. GitHub의 새 저장소를 만듭니다. 예: heritage-exhibit.
2. Add file → Upload files에서 이 폴더 안의 파일과 assets 폴더를 올리고 Commit changes를 누릅니다. ZIP 파일 자체를 올리면 전시가 열리지 않습니다.
3. Settings → Pages → Build and deployment → Source에서 Deploy from a branch를 선택합니다.
4. main 브랜치와 /(root) 폴더를 선택하고 Save를 누릅니다.
5. 배포가 끝나면 Pages 화면에 나오는 Visit site로 확인합니다.

일반적인 주소: https://ge2ggo.github.io/저장소명/

## 구성

HTML·CSS·JavaScript로 된 정적 사이트입니다. 패키지 설치·빌드·비밀키·별도 서버가 필요 없습니다. 사진·글꼴도 모두 이 폴더에 있습니다. assets 폴더의 구조와 파일 이름을 유지해주세요.

입력한 문장은 서버에 전송하거나 자동 저장하지 않습니다. 새로고침하면 사라집니다. 카드 내려받기를 선택한 경우에만 PNG가 기기에 저장됩니다.

역사 자료와 사진의 이용 조건은 sources.md에 있습니다. SUIT 폰트와 함께 assets/fonts/SUIT-OFL.txt를 배포합니다.

공개 후 휴대폰·로그아웃 상태에서 사진 확대, 질문·해설, 개인 카드 내려받기를 확인해주세요.
